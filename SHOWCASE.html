01

自主度光谱：Agent 还是 Workflow？

判断"是不是 Agent"看四点——自主决定下一步 / 用工具 / 带反馈的循环 / 朝目标推进。同一套基线上，从"刻意反 Agent 的可控管道"到"真正自主的 Agent"逐级铺开。点击任意行看该模块的判定理由 / 开关 / 端点 / 适用场景。
← 确定性 · 可控 · 合规自主 · 开放式循环 →
自主度模块 / 端点是 Agent 吗说明
可控管道/chat · RAG · /extract · /chat/vision · NL2SQL❌ 不是单次 LLM 调用的确定性链路。NL2SQL 有 6 层护栏，刻意反 Agent
确定性编排workflow（Flowable 退款审批）❌ 相反写死的 BPMN 流程 + 人工审批，与 Agent 正相反
Prompt Chainingai/chaining · /chat/chain❌ 不是预定义顺序编排 + 步间确定性 gate 短路
Routingai/routing · /chat/auto❌ 不是分类 → 分派到专门链路
工具自主Assistant.chat + @Tool🟡 半个模型自主决定"要不要调工具"，走原生 function-calling 隐式循环
Evaluator-Optimizerreflexion · /chat/reflexive🟡 litegenerate→critique→improve，有反馈循环但结构固定
Votingai/voting · /chat/vote🟡 编排同任务并行 N 次取共识（多数表决 / 聚合）
Orchestrator-Workersmultiagent · /chat/multi-agent🟡 编排模型拆任务，但执行是固定 DAG，不中途动态选工具
自主 Agentai/agent · /agent/run✅ 是开放式 plan→act→observe：每步自己决定动作、用工具、观察、再决策

面试话术：生产里很多场景要的是可控管道而非自主 Agent（NL2SQL 要护栏、审批要合规流程 + 人工兜底）。两种范式并存、按场景选型，才是这个项目面向落地的完整性所在——deep-agent 是其中那个真正自主的 Agent。

多 Provider 统一抽象

RAG 的深度（不止"检索+拼接"）

03

自主 Agent + Loop Engineering

deep-agent 开放式 plan→act→observe 循环，模型每步自己决定动作，可插拔工具（RAG / NL2SQL / MCP / Browser-use / Code Interpreter）。

04

Anthropic Workflow 模式全覆盖

《Building Effective Agents》的 5 种 workflow + agent 逐一落地并映射到代码：Prompt Chaining / Routing / Parallelization·Voting / Orchestrator-Workers / Evaluator-Optimizer / Agent。

05

NL2SQL 的 6 层安全护栏

自然语言 → SQL → 只读执行 → 解读的受控链路：L1 只读账号 / L2 语句白名单 / L3 表白名单 / L4 强制 LIMIT / L5 超时 / L6 租户谓词，外加数字 grounding 核对答案数字 ∈ 查询结果。

为什么：LLM 生成 SQL 直连生产库是高危动作，这套护栏体现"给 LLM 能力也给它笼子"的安全意识。

06

Eval Harness + Baseline CI 门禁

把 prompt 当代码测：黄金集 + LLM-as-Judge（客观字段规则匹配、主观分 temp=0 稳定打分）+ multi-run 看方差 + baseline 门禁（回归返 HTTP 422 卡 CI，还挡"偷偷删 case 让门禁变绿"）。

为什么：绝大多数候选人改 prompt 靠"感觉"，这套把 LLM 行为纳入可回归、可门禁的工程体系——是资深信号。

五分钟 Live Demo

前置：ollama pull llama3.1 && ollama pull nomic-embed-text，然后 mvn spring-boot:run。零配置就是 Ollama + InMemory 的最小可跑形态。
bash — 5-minute demo
# ① RAG + 引用：入库 → 带 [doc=来源] 提问
curl -X POST localhost:8080/rag/ingest
curl -X POST 'localhost:8080/chat?chatId=demo' -H 'Content-Type: application/json' \
  -d '{"message":"根据文档介绍这个项目的 RAG 能力，并标注来源"}'

# ② 工具调用：模型自主决定调用时间工具
curl -X POST 'localhost:8080/chat?chatId=demo' -H 'Content-Type: application/json' \
  -d '{"message":"现在几点？时区 Asia/Shanghai"}'

# ③ 自主 Agent：看完整 plan→act→observe trace + stopReason
#    启动加 --app.deep-agent.enabled=true --app.llm.ollama.model-name=qwen2.5
curl -X POST 'localhost:8080/agent/run' -H 'Content-Type: application/json' \
  -d '{"goal":"用工具查出当前时间，再算出距离今年国庆还有多少天"}'

# ④ 质量回归：一条命令看整套黄金集的 passRate / 分数方差
curl -X POST 'localhost:8080/eval/run?runs=3'

# ⑤ 可观测：token 用量 / Prometheus 指标
curl localhost:8080/actuator/metrics/gen_ai.client.token.usage
